# SMART HUB — frontend

Application Angular de SMART HUB. Lancement, déploiement et configuration :
voir le [README à la racine du dépôt](../README.md).

```bash
npm install
npm start        # http://localhost:4200, API attendue sur http://127.0.0.1:8000
npm run build    # build de production (utilisé par le Dockerfile)
```
